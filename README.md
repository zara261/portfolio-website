Run Locally
This is a static website, so no backend server or package installation is required to preview the basic portfolio.
1. Clone the repository:
   git clone https://github.com/zara261/portfolio-repo.git
2. Open the project folder:
   cd portfolio-repo
3. Open index.html in your browser.
You can also use the Live Server extension in Visual Studio Code for local preview.
Deploy with GitHub Pages
The website is hosted using GitHub Pages.

For the site and CV download buttons to work correctly, keep these files in the repository root:
portfolio-repo/
├── index.html
├── Zara_Batool_CV.pdf
└── README.md
If you update the website or CV, upload the changed files to the same repository and commit the changes to the branch configured in GitHub Pages. GitHub Pages will publish the updated site after deployment completes.
CV
The portfolio includes buttons that download Zara_Batool_CV.pdf. Keep the PDF filename exactly the same as the link in index.html, or update the HTML links if you rename the file.
